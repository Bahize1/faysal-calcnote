FAYSAL CALCNOTE – APK pour tester avec 3 personnes (gratuit)

1. Crée un compte sur github.com (gratuit) puis un nouveau dépôt « faysal-calcnote ».
2. Envoie-y TOUT le contenu de ce dossier (y compris le dossier caché .github).
   Astuce : « Add file > Upload files », glisse tous les fichiers et dossiers.
3. Onglet « Actions » > « Construire l'APK » > « Run workflow ». Attends ~5 minutes.
4. Ouvre l'exécution terminée > « Artifacts » > télécharge « Faysal-CalcNote-APK » (zip contenant app-debug.apk).
5. Envoie app-debug.apk par WhatsApp à tes testeurs. Sur Android :
   ouvrir le fichier > autoriser « sources inconnues » > Installer.

Cette APK fonctionne sans Internet et sans Netlify.
Pour le Play Store plus tard, il faudra une version signée (.aab) : on la prépare ensemble.
